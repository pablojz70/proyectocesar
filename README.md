PROPUESTA DE PROYECTO
SISTEMA DE VENTAS Y CRÉDITOS 

Versión: 1.0
Fecha: Mayo 2026
Plataforma: Web (en línea)
🎯 OBJETIVO GENERAL

Desarrollar un sistema de ventas web que permita a los vendedores:

    Iniciar sesión de forma segura.

    Gestionar sus propios clientes.

    Administrar productos.

    Controlar inventario de productos.

    Registrar ventas al contado o crédito, con conversión automática de Euros a Bolívares.

    Consultar deudas de clientes y registrar pagos.

    Generar reportes básicos de ventas, rentabilidad y stock.

    Registrar préstamos a clientes con cálculo automático de intereses.
